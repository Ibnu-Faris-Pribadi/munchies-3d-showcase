# Munchies — Interactive 3D Web & Franchise Simulation

Website interaktif 3D untuk brand **Munchies** (Pisang Goreng, Roti Bakar, & Pancong Lumer) yang dilengkapi katalog menu 3D serta simulasi outlet franchise secara *real-time* langsung di browser.

## Live Demo
👉 **[Buka Website Munchies di sini](https://munchiesdessert.netlify.app)**

## Fitur Utama
- **Interactive Hero & 3D Pop-Out Menu:** Tampilan menu dengan efek kedalaman 3D dan detail varian rasa.
- **Franchise Packages:** Informasi paket kemitraan Standar & Premium dengan tampilan responsif untuk desktop dan HP.
- **Simulasi 3D Franchise (Three.js):**
  - 6 pilihan aset outlet (Booth Portabel, Gerobak Dagang, Sepeda Listrik Kargo, Booth Kontainer, Ruko Takeaway, dan Restoran 2 Lantai) + Kompleks Gabungan Kota.
  - Penggaris **Ukuran 3D** dan daftar **Detail Mitra** secara *real-time*.
  - **Mode Orbit** (putar 360°) dan **Mode Jelajah** (jalan kaki, ambil objek, dorong gerobak, dan kendarai sepeda listrik).
  - Kontrol **Analog Bulat Multi-Touch** khusus perangkat mobile (bisa berjalan sambil menengok bersamaan).

## Tech Stack
HTML5, CSS3, JavaScript, Three.js, dan Blender (3D Modeling).
